# Mi rutina

App web instalable (PWA) para seguir una rutina de gimnasio: series con kilos y repeticiones, temporizador de descanso con alarma, calendario, progreso por ejercicio, series por músculo y peso corporal.

**Usarla:** https://ltp22.github.io/RutinaGym/

En el celular, ábrela en el navegador y agrégala a la pantalla de inicio (Safari: Compartir → Agregar a inicio · Chrome: menú ⋮ → Instalar app). Se abre en pantalla completa y funciona sin conexión.
